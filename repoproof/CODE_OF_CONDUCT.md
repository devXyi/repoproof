# Code of conduct

RepoProof is a project for people who care about making software easier to start with. We want
everyone who takes part to feel welcome, whatever their background or experience.

## What we expect

- Be kind and assume good intent. Disagree with ideas, not people.
- Welcome newcomers. Everyone was new once, and "this was confusing" is a useful bug report.
- Give feedback that is specific and actionable, and receive it graciously.
- Respect each other's time: keep discussions on topic and issues reproducible.

## What is not acceptable

Harassment, discrimination, personal attacks, trolling, publishing other people's private
information, and anything else that would make a reasonable person feel unwelcome.

## Enforcement

Maintainers may edit or remove comments, close discussions and, if needed, block people who
break these rules. To report a problem, message a maintainer privately on GitHub or use the
repository's private vulnerability reporting form (Security tab) if you need to keep it
confidential. Reports are handled with discretion.

This code applies in all project spaces: issues, pull requests, discussions and reviews.
